## RQ1 — Positional Encoding in NoPE Global Layers

**Research question**: Do NoPE Global hidden states contain positional information,
and is this signal generated by Global layers or propagated from preceding SWA layers?

### Hypothesis set

**H1_null** (Global propagates only):
> The positional information in Global layer hidden states is entirely a carry-over
> from preceding SWA layers. The delta probe accuracy at Global layer outputs will
> not significantly exceed the accuracy at Global layer inputs (delta ≈ 0).

**H1_alt** (Global independently encodes):
> NoPE Global layers actively contribute to positional encoding. The delta probe
> accuracy (acc(h_out) − acc(h_in)) at one or more Global layer indices will
> significantly exceed zero, with Cohen's d ≥ 0.5 after Holm correction.

**Primary experiment**: e008 (delta-attribution probe, PRE-REGISTERED)
**Supporting evidence**: e003, e004 (retrofitted; establish that position is present,
but cannot distinguish H1_null from H1_alt)

### Decision rule (e008 primary)
```criteria
metric: probe_accuracy_delta
direction: global_out > global_in
accept:
  min_abs_cohen_d: 0.5
  max_p_holm_corrected: 0.01
reject_null_if:
  # Accept H1_alt if delta is significant at >= 1 Global layer
  min_layers_significant: 1
min_n_per_group: 300
n_simultaneous_tests: 16  # one per Global layer index
bootstrap_n: 10000
retrofitted: false
```

**Stopping rule**: If model OOM prevents running 300-prompt extraction, reduce to
100 prompts and re-tag result as EXPLORATORY. Do not claim confirmatory evidence
with n < 100.

## RQ2 — Attention Pattern Divergence (SWA vs Global)

**Research question**: Do SWA and Global exhibit functionally different attention
patterns, and at what sequence length does any difference emerge?

### Hypothesis set

**H2_null** (no divergence):
> Attention entropy and mean attention distance are not significantly different
> between Global and SWA layers at any tested sequence length (128–8,192 tokens).

**H2_alt** (divergence above half-window):
> At sequence lengths ≥ 2,048 tokens (≥ SWA_window/2), Global attention entropy
> and/or mean attention distance significantly exceeds SWA values, with Cohen's d
> ≥ 0.5 after Holm correction across all tested length conditions.

**Primary experiments**: e001, e002 (both RETROFITTED)

### Decision rule (e002, retrofitted)
```criteria
metric: entropy
direction: global_nope > swa
accept:
  min_abs_cohen_d: 0.5
  max_p_holm_corrected: 0.01
min_n_per_group: 10
n_simultaneous_tests: 5  # five length conditions: 128, 256, 512, 1024, 2048
bootstrap_n: 10000
retrofitted: true
note: "Single input per length condition in original run. Must rerun with n>=10 inputs per length."
```

**Known limitation**: Original Exp 1b may have used a single text input per length
condition. If so, n_a = n_b = n_layers = 16 (one value per Global layer), which gives
adequate within-condition n for entropy, but the between-condition comparison is
confounded by document identity. Rerun with ≥ 10 distinct documents per length before
claiming H2_alt confirmed.

## RQ3 — Causal Contribution of Global to Long-Range Dependency

**Research question**: Does NoPE Global Attention make a causal contribution to
long-range dependency beyond what SWA alone provides?

### Hypothesis set

**H3_null** (Global does not contribute causally):
> Ablating or constraining Global layers' ability to attend beyond the SWA window
> does not significantly change model behavior. Specifically: (a) SWA mask injection
> into Global layers does not significantly change perplexity; (b) zeroing Global
> attention output does not significantly change perplexity or recall accuracy;
> (c) Global attention distance does not grow faster than SWA at lengths > 4,096.

**H3_alt** (Global contributes causally):
> At least two of the three following conditions hold with Cohen's d ≥ 0.5 and
> Holm-corrected p ≤ 0.01:
> 1. [e005] SWA mask injection into Global layers significantly increases perplexity
>    at token positions > 4,096 tokens.
> 2. [e006] Zeroing Global attention output significantly degrades perplexity.
> 3. [e007] Global attention distance continues growing beyond 4,096-token SWA window
>    saturation, significantly diverging from SWA distance at ≥ 2 length conditions.

**Decision rule**: 2-of-3 majority (see HANDOVER.md Section 2b for full operational
definition and conflict resolution protocol).

### Decision rule (e005 — SWA mask ablation, PRE-REGISTERED)
```criteria
metric: perplexity_delta
direction: ablated > baseline  # higher perplexity = worse
accept:
  min_abs_cohen_d: 0.5
  max_p_holm_corrected: 0.01
conditions:
  token_position_filter: "> 4096"  # measure only at positions beyond SWA window
min_n_per_group: 20
n_simultaneous_tests: 1
bootstrap_n: 10000
retrofitted: false
```

### Decision rule (e006 — Global zero ablation, PRE-REGISTERED)
```criteria
metric: perplexity_delta
direction: ablated > baseline
accept:
  min_abs_cohen_d: 0.5
  max_p_holm_corrected: 0.01
min_n_per_group: 20
```

### Decision rule (e007 — long context hooks, PRE-REGISTERED)

## Stopping rules

1. **OOM**: If any experiment encounters GPU OOM, reduce sequence length or batch size.
   Reduce n_simultaneous_tests accordingly and re-register in this document.
2. **Null result**: A FAILED verdict ends the experiment for that hypothesis.
   Do not add more prompts or tweak parameters to hunt for significance.
3. **Model unavailability**: If model cache cannot be downloaded within 2 hours,
   experiment is deferred. This is not a valid reason to change hypotheses.
4. **Timing**: All pre-registered experiments (e005–e008) must be completed within
   90 days of this registration date (deadline: 2026-07-26).
